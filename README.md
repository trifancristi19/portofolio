# Cristian Trifan - Portfolio

A modern, interactive portfolio website with a hacker-themed design.

## Features

- Responsive design for all devices
- Matrix-style animation background
- Interactive terminal-styled sections
- Glitch text effects and typewriter animations
- Smooth scrolling and section reveal animations
- Profile picture with glowing animation
- Downloadable CV/Resume

## Technologies Used

- HTML5
- CSS3 (with modern animations and effects)
- JavaScript (ES6+)
- Canvas API for Matrix rain effect

## Sections

- About: Professional summary and skills
- Education: Academic background
- Experience: Work history
- Projects & Certifications: Technical accomplishments and courses
- Contact: Ways to get in touch and CV download

## File Structure

```
├── index.html               # Main HTML file
├── css/
│   └── style.css            # CSS styles
├── js/
│   └── script.js            # JavaScript animations and interactions
├── assets/
│   ├── images/              # Profile picture and other images
│   └── cv/                  # CV/Resume files
├── CUSTOMIZATION.md         # Guide for customizing the portfolio
└── README.md                # Project information
```

## Development

To run this project locally:

1. Clone the repository
2. Add your profile picture to `assets/images/`
3. Add your CV to `assets/cv/`
4. Open `index.html` in your browser

## Deployment

The website is hosted using GitHub Pages.
